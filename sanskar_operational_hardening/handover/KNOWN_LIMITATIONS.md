# KNOWN LIMITATIONS

Current implementation is designed for educational distributed simulation.

Known limitations:

- Single machine deployment

- Local replay storage

- No real service mesh

- No Kubernetes deployment

- OpenTelemetry not integrated

- Failure injection is simulated

- Consensus algorithm not implemented

Future work:

- gRPC communication

- Redis replay storage

- Kafka telemetry

- OpenTelemetry Collector

- Kubernetes deployment

- Prometheus metrics
